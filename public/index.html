Three steps

How it works

  1. Sign up

    Email + password (8+ characters). Account is created in Postgres with a bcrypt hash.

  2. Add notes

    Each note you create persists to the database, scoped to your account.

  3. Watch the admin chart

    The first account is admin and gets a 30-day registration chart on the dashboard.

Every action, on the record

Watch, don't guess

Every note carries a timestamp. Password changes are audited server-side. The chart on the dashboard is built from real registration events — not interpolated, not seeded. 

$ POST /api/notes  body="ship the rebrand"
→ 201  note_id=42  created_at=2026-10-13T14:02:11Z
# write timestamp · server clock · Postgres default

Agents run in their own box

Security

  • Bcrypt-hashed passwords

    Passwords are hashed with bcrypt at cost 10 on signup. We never see plaintext again.

  • Signed session cookies

    httpOnly, sameSite=lax, scoped to this workspace. Signed with a server-only secret.

  • Same-origin forms

    No third-party trackers, no cross-site requests, no embedded analytics.

  • Hardened container

    Resource caps, no Docker socket, isolated filesystem per workspace.

Asked and answered

FAQ

Where does this app actually run?

On EasyCoder's infra, in a per-workspace container. The repo publishes to https://test.app.easycoder.dev.

Is my password stored safely?

Yes — bcrypt-hashed at cost 10, salted per account. We never see the plaintext after signup.

Can I delete my account?

Not yet from the UI. The data lives in Postgres on the platform side; a self-serve flow is on the roadmap.

Is this the EasyCoder platform itself?

No — it's a small demo app shipped from an EasyCoder workspace, like every other workspace.
