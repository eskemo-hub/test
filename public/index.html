What this is

A clean, single-page starting point for the test repo. It is a static site served straight from the repo — open index.html in a browser and it works. The styling lives in styles.css so it stays easy to tweak.

It uses the system font stack so it renders instantly on any device, and it adapts to your system's light or dark theme automatically.

This build also includes a small auth demo: a real Postgres-backed register and login form, a signed session cookie, and a protected dashboard at /dashboard.html.

Features

  • No build tooling

    Edit HTML and CSS, refresh the browser, ship. That's the whole loop.

  • Responsive by default

    Layouts adapt from phone to wide desktop without media-query gymnastics.

  • System fonts

    Uses the platform's UI font — no network calls, no flash of unstyled text.

  • Real auth

    Backed by a real Postgres database with bcrypt password hashing and signed cookies.

Ready when you are.
